================================================================================
                    HOW TO ADD RATE TO CROP INVERT DETAIL
                          STEP-BY-STEP INSTRUCTIONS
================================================================================

This update moves the Rate column from Master table to Detail table in the
Direct Inward form. This allows each detail row to have its own rate.

================================================================================
METHOD 1: Using SQL Server Management Studio (RECOMMENDED)
================================================================================

Step 1: Open SSMS
-----------------
   1. Click Start menu
   2. Search for "SQL Server Management Studio"
   3. Click to open

Step 2: Connect to database
---------------------------
   In the Connect dialog:

   Server type:       Database Engine
   Server name:       ADSVR\SQLEXPRESS01
   Authentication:    SQL Server Authentication
   Login:             sa
   Password:          123456

   Click: [Connect]

Step 3: Open the SQL script
---------------------------
   1. Click menu: File → Open → File
   2. Navigate to: D:\SFC\Backend\Database_Scripts\
   3. Select: Add_Rate_To_CropInvertDetail.sql
   4. Click: [Open]

Step 4: Run the script
----------------------
   1. Make sure you're connected to InventoryManagement database
      (Check dropdown at top of window)

   2. Press F5 key
      OR
      Click the [Execute] button (green play icon)
      OR
      Click menu: Query → Execute

Step 5: Check results
---------------------
   Look at the Messages tab (bottom of screen)

   You should see:
   ✓ SP_AddUpdCropInvertDetail found in database
   ✓ RATE column added to table (if didn't exist)
   ✓ Old SP dropped
   ✓ Updated SP created successfully with @RATE parameter
   ✓ VERIFICATION PASSED: @RATE parameter exists
   ✓ UPDATE COMPLETE!

Step 6: Restart backend
----------------------
   Go to your backend CMD window
   Press: Ctrl+C
   Type: Y
   Run: dotnet run

FINISHED! Test Direct Inward functionality now.

================================================================================
VERIFICATION: Check if it worked
================================================================================

After running the script, verify the fix worked:

Step 1: Check SP parameters
----------------------------
   In SSMS, run this query:

   SELECT
       PARAMETER_NAME,
       DATA_TYPE
   FROM INFORMATION_SCHEMA.PARAMETERS
   WHERE SPECIFIC_NAME = 'SP_AddUpdCropInvertDetail'
   AND PARAMETER_NAME = '@RATE'

   You should see:
   PARAMETER_NAME   DATA_TYPE
   @RATE            decimal

   ✓ If you see this = SUCCESS!
   ✗ If you see 0 rows = Script didn't run correctly, try again

Step 2: Check table structure
------------------------------
   In SSMS, run this query:

   SELECT
       COLUMN_NAME,
       DATA_TYPE
   FROM INFORMATION_SCHEMA.COLUMNS
   WHERE TABLE_NAME = 'tblCropDirectInvertDetail'
   AND COLUMN_NAME = 'RATE'

   You should see:
   COLUMN_NAME   DATA_TYPE
   RATE          decimal

   ✓ If you see this = Table has Rate column!

Step 3: Test in application
----------------------------
   1. Make sure backend is running
   2. Open frontend: http://localhost:5173
   3. Go to Direct Inward form
   4. Fill in farmer details
   5. Enter packing size, quantity, weight, and RATE
   6. Click "Add Data"
   7. Should work without errors!

Step 4: Verify data was saved
------------------------------
   In SSMS, run this query:

   SELECT TOP 5
       CDAID,
       CROPID,
       WEIGHT,
       RATE,  -- Should have value!
       PQUNTITY,
       CGRADE
   FROM tblCropDirectInvertDetail
   WHERE ISDELETED = 0
   ORDER BY CDAID DESC

   Check: RATE column should have the rate you entered
   ✓ If it has a value = WORKING PERFECTLY!

================================================================================
TROUBLESHOOTING
================================================================================

Error: "Cannot open database"
-----------------------------
Solution:
   - Make sure SQL Server is running
   - Check server name: ADSVR\SQLEXPRESS01
   - Verify database exists: InventoryManagement

Error: "Login failed for user 'sa'"
----------------------------------
Solution:
   - Check password: 123456
   - Verify SQL Server Authentication is enabled

Error: "Invalid column name 'RATE'" (after update)
--------------------------------------------------
Solution:
   The script should have added the column automatically.
   If not, run this manually in SSMS:

   ALTER TABLE tblCropDirectInvertDetail
   ADD RATE DECIMAL(18,2) NULL

Error: "Procedure has too many arguments" (in backend)
------------------------------------------------------
Solution:
   The SP update didn't work properly.
   Run the script again in SSMS.
