STEP 2: GET FROM DATABASE AND UPDATE
================================================================================

File: Get_Current_SP_And_Update.sql
Purpose: Gets actual SP from database, then updates it with PAYMENTDT parameter

What it does:
-------------
1. GETS the current stored procedure from database
2. SHOWS what parameters it currently has
3. CHECKS if @PAYMENTDT exists
4. If missing: DROPS old version
5. CREATES new version with @PAYMENTDT parameter
6. VERIFIES the update was successful
7. SHOWS the updated parameter list

How to run:
-----------
1. Open SSMS
2. Connect to: ADSVR\SQLEXPRESS01 (InventoryManagement database)
3. Open: D:\SFC\Backend\Database_Scripts\Get_Current_SP_And_Update.sql
4. Press F5 (Execute)

RECOMMENDED WORKFLOW
================================================================================

First Time:
-----------
1. Run: Show_Current_SP_Only.sql
   → See what's currently in database
   → Check if update is needed

2. If update needed:
   Run: Get_Current_SP_And_Update.sql
   → Gets current SP from database
   → Updates it with PAYMENTDT parameter

3. Restart backend server
   → Ctrl+C in backend window
   → dotnet run

4. Test payment functionality
   → Select payment date
   → Save transaction
   → Verify in database

Subsequent Times:
-----------------
1. Run: Show_Current_SP_Only.sql
   → Should show "✓ @PAYMENTDT parameter EXISTS"
   → Should show "Status: Stored procedure is up to date!"
