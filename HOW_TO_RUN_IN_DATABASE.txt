================================================================================
COMMON ERRORS AND SOLUTIONS
================================================================================

Error: "Cannot open database"
-----------------------------
Solution:
   - Make sure SQL Server is running
   - Check server name: ADSVR\SQLEXPRESS01
   - Verify database exists: InventoryManagement

Error: "Login failed for user 'sa'"
----------------------------------
Solution:
   - Check password: 123456
   - Verify SQL Server Authentication is enabled
   - Try logging in with SSMS first to test credentials

Error: "sqlcmd is not recognized"
--------------------------------
Solution:
   Use METHOD 1 or METHOD 2 instead
   (sqlcmd is not installed on your system)

Error: "Procedure has too many arguments" (in backend)
-----------------------------------------------------
Solution:
   The script hasn't run yet!
   Go back and run it using METHOD 1 or METHOD 2

Error: "Invalid column name 'PAYMENTDT'"
---------------------------------------
Solution:
   The table doesn't have the column yet.
   Run this script first in SSMS:

   D:\SFC\Backend\Database_Scripts\Add_PaymentDate_Column.sql

   Then run the SP update script again.
