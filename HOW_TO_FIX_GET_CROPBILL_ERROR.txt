              FIX: GET_CropBill "varchar to numeric" ERROR
                        QUICK SOLUTION GUIDE
================================================================================

ERROR MESSAGE:
==============
http://localhost:5173/backend/api/GET_CropBill
Internal server error: Error converting data type varchar to numeric.

ROOT CAUSE:
===========
The SQL function GET_CropBill is trying to return RATE as varchar, but the
C# code expects it as a double/numeric value.

This happened because:
1. We moved RATE column from Master table to Detail table
2. The GET_CropBill function still pulls RATE from Master table
3. Or it's using a string aggregation function on RATE

STEP 2: Fix the Function
-------------------------
After running the diagnostic, you'll see the full function definition.

The fix is to change how RATE is calculated. Here are the options:

OPTION A: Weighted Average (RECOMMENDED)
-----------------------------------------
This calculates the average rate weighted by quantity/weight.

Find the line that selects RATE in the function and replace it with:

  CASE
    WHEN SUM(d.WEIGHT) > 0 THEN
      CAST(SUM(d.WEIGHT * d.RATE) / SUM(d.WEIGHT) AS DECIMAL(18,2))
    ELSE CAST(0 AS DECIMAL(18,2))
  END AS RATE

And make sure the FROM clause includes the detail table:

  FROM tblCropInvertDetail d  -- or tblCropDirectInvertDetail
  WHERE d.CROPID = @CROPID
  AND d.ISDELETED = 0


OPTION B: Simple Average
-------------------------
This just averages all rates regardless of weight:

  CAST(AVG(d.RATE) AS DECIMAL(18,2)) AS RATE


OPTION C: First Row Rate
-------------------------
This takes the rate from the first detail row:

  CAST((SELECT TOP 1 RATE FROM tblCropInvertDetail
        WHERE CROPID = @CROPID AND ISDELETED = 0) AS DECIMAL(18,2)) AS RATE


OPTION D: Return NULL (If RATE not needed)
-------------------------------------------
If the GET_CropBill view doesn't actually need RATE:

  CAST(NULL AS DECIMAL(18,2)) AS RATE

================================================================================
COMPLETE EXAMPLE FUNCTION
================================================================================

Here's a complete example of what the fixed function might look like:

CREATE OR ALTER FUNCTION [dbo].[GET_CropBill]
(
    @CROPID VARCHAR(50),
    @COMPANYID VARCHAR(50),
    @DEPTID VARCHAR(50)
)
RETURNS TABLE
AS
RETURN
(
    SELECT
        m.CROPID,
        m.CBKID,
        m.VISITINGDATE,
        m.NARR,
        m.PHONENUMBER,
        m.CTYPE,
        m.CVARIETY,
        m.CAREA,
        m.FARMERNAME,
        m.CROPNAME,
        m.FAID,

        -- RATE calculated from detail table (FIXED)
        CASE
            WHEN SUM(d.WEIGHT) > 0 THEN
                CAST(SUM(d.WEIGHT * d.RATE) / SUM(d.WEIGHT) AS DECIMAL(18,2))
            ELSE CAST(0 AS DECIMAL(18,2))
        END AS RATE,

        m.WEIGHT,
        m.CARET,
        m.AMOUNT,
        m.ADVANCE,
        m.CDAID,
        m.VDAID,
        m.BILLSTATUS
    FROM tblCropInvertMaster m
    LEFT JOIN tblCropInvertDetail d ON m.CROPID = d.CROPID AND d.ISDELETED = 0
    WHERE m.CROPID = @CROPID
      AND m.COMPANYID = @COMPANYID
      AND m.DEPTID = @DEPTID
      AND m.ISDELETED = 0
    GROUP BY
        m.CROPID, m.CBKID, m.VISITINGDATE, m.NARR, m.PHONENUMBER,
        m.CTYPE, m.CVARIETY, m.CAREA, m.FARMERNAME, m.CROPNAME,
        m.FAID, m.WEIGHT, m.CARET, m.AMOUNT, m.ADVANCE,
        m.CDAID, m.VDAID, m.BILLSTATUS
)
GO

================================================================================
TROUBLESHOOTING
================================================================================

Error: "Function GET_CropBill not found"
----------------------------------------
The function might have a different name. Run:

  SELECT name FROM sys.objects
  WHERE type IN ('FN', 'IF', 'TF')
  AND name LIKE '%CropBill%'


Error: "Invalid object name 'tblCropInvertDetail'"
--------------------------------------------------
Your database uses tblCropDirectInvertDetail instead.
Change the JOIN to use that table name.


Error: "Column 'RATE' is invalid in the select list"
----------------------------------------------------
When using aggregate functions (SUM, AVG), you need GROUP BY.
Add all non-aggregated columns to GROUP BY clause.


Still getting varchar error:
-----------------------------
1. Check master table RATE column type:
   SELECT DATA_TYPE
   FROM INFORMATION_SCHEMA.COLUMNS
   WHERE TABLE_NAME = 'tblCropInvertMaster'
   AND COLUMN_NAME = 'RATE'

   If it's varchar, you need to also add CAST in the function.

2. Make sure detail table RATE is DECIMAL:
   Run Add_Rate_To_CropInvertDetail.sql if not done yet


Function updated but still erroring:
------------------------------------
1. Make sure you restarted the backend server
2. Clear browser cache (Ctrl+Shift+Delete)
3. Check backend console for SQL error details
